# 너반꿀 앱 리디자인 구현 — 원본 명세

2026-10-10 에 받은 작업 지시 원문이다. 진행 상황·결정 사항은 `docs/redesign-progress.md` 에 있다.
시안은 `design/*.png` (화면별·상태별 1장, `00-overview.png`·`00-tokens.png` 는 개요). 시안과 이 명세가 다르면 시안을 따른다.

## 맥락
- 이 저장소는 Flutter 모바일 앱 '너반꿀'이다. 주식·코인 손절(손실)을 금액과 함께 인증하고 서로 위로하는 커뮤니티 앱으로, 손실액이 큰 순서로 주간 랭킹을 매긴다.
- 현재 Material 2(useMaterial3: false), Android 우선, 세로 전용, 라이트 모드만 있다.
- 목표: **기능·API·데이터 모델은 그대로 두고 UI만 새 디자인 시스템으로 다시 그린다.**
- 디자인 시안은 `design/` 폴더의 PNG다(화면별·상태별 1장). 시작 전에 전부 열어 보고, 구현 중에도 해당 화면 시안을 다시 확인해라. 시안과 아래 명세가 다르면 시안을 따르고 나에게 알려라.
- 서버 저장소: 없음(경로 미제공) — 배지 이미지는 `public/badge/0~19.png`, 휘장 이미지는 `public/insignia/0~29.png`로 서빙된다. 앱은 URL로 받는다.

## 작업 규칙
1. 코드부터 바꾸지 말고 먼저 탐색해라: 화면 목록과 라우팅, API 레이어, 기존 테마·TextStyle 정의 위치, 공용 위젯, 토스트/다이얼로그 구현 방식, 하단 탭바 아이콘 에셋 유무를 파악하고 **단계별 계획을 먼저 보여준 뒤** 내 승인을 받고 시작해라.
2. 아래 1→5단계 순서로 진행한다. 각 단계가 끝날 때마다 `flutter analyze` 경고 0, 디버그 빌드 성공을 확인하고 단계 단위로 커밋해라(커밋 메시지는 한국어).
3. API 호출, 모델 클래스, 상태 관리 로직은 건드리지 마라. 꼭 필요하면(예: 서버가 주는 myRating을 UI에 표시) 읽기만 추가하고 이유를 설명해라.
4. 화면마다 따로 정의된 TextStyle·색상 리터럴은 모두 토큰으로 교체한다. 작업이 끝났을 때 `lib/` 안에 `Color(0x…)`·`fontSize:` 리터럴이 테마 파일 밖에 남아 있으면 안 된다.
5. 모르는 것은 추측하지 말고 질문해라. 특히 기존 동작을 바꾸게 되는 지점은 반드시 먼저 물어라.

## 2단계 — 공통 컴포넌트 (`lib/widgets/`)
각 컴포넌트는 한 파일, 외부에서 토큰 외의 색·크기를 넘기지 않게 만든다.

- `AuthorInfo` — 배지(프로필 이미지) + 닉네임 + 휘장 최대 2개. 크기 variant: small(배지 22, 닉네임 label) / medium(배지 36, 닉네임 14 w700). 배지는 모서리 6/10, 배경 surface, 로드 실패 시 너반꿀 심볼.
  - **휘장 렌더링 주의**: 휘장 PNG는 400×400이지만 실제 그림은 가운데 가로로 좁게 들어 있다. 정사각형으로 그대로 넣으면 안 읽히므로, small은 `SizedBox(34×18)` 안에 `ClipRect → OverflowBox(38×38) → Image`로 투명 여백을 잘라내 보여준다. medium은 40×22 박스에 46×46 이미지.
- `LossAmount` — `-1,250,000원` 형식 하나로 통일(마이너스 + 천 단위 콤마 + 원, loss 색, tabular). 크기 variant: list 22, detail 24, rank 15~20. 1억 이상은 `-1.2억원`으로 축약하는 옵션. 목록·상세·랭킹 모두 이 위젯만 쓴다(현재 상세는 회색·마이너스 없음, 랭킹은 콤마 없음 → 모두 교체).
- `NbkPill` — 작은 필 배지. variant: loss(lossTint/loss), honey(honeyTint/honeyDeep), neutral(surface/text2). '주식'/'코인'/'손실'/'추천 128'/'내 글'에 사용.
- `ReactionButton` — 좋아요/싫어요 카운터. `selected` 상태 필수: 미선택은 외곽선 아이콘 + text3, 좋아요 선택은 honey 채움 아이콘 + honeyDeep 글자(상세에서는 honeyTint 배경 필 버튼), 싫어요 선택은 lossTint/loss. 서버의 `myRating`으로 초기 상태 표시.
- `NbkAppBar` — 높이 56. `leading` 규칙을 enum으로 강제: `back`(스택 이동 화면: 상세·내 정보·랭킹) / `close`(모달·폼: 로그인·글 작성·프로필 수정). 오른쪽 액션은 텍스트 링크가 아니라 필 버튼(`NbkPillButton`)으로.
- 버튼 — `NbkButton.primary`(honey/onHoney, 높이 48~52), `.danger`(danger/흰), `.secondary`(surface/text1), `.outline`(흰/line 테두리, 필). 비활성은 line 배경 + hint 글자. 상단바용 작은 필 버튼 높이 36.
- `NbkToast` — 배경은 항상 text1, 모서리 12, 높이 44~48, 왼쪽 아이콘 색만 상태 구분(성공 #5BD38E 체크 / 안내 honey / 오류 #FF8A80). 기존 빨강·검정 제각각 토스트 전부 이걸로 교체.
- `ConfirmSheet`(바텀시트) / `ConfirmDialog` — 제목 + 설명 + [위험 액션(danger)] [취소(secondary)]. 삭제·탈퇴는 반드시 이걸 거친다.
- `Skeleton` — shimmer 박스. 목록 아이템/Top3 카드/랭킹 행 스켈레톤 조합 제공.
- `EmptyState` / `ErrorState` — 아이콘 타일(96, 모서리 28) + 제목(heading) + 설명(body text3) + 선택적 CTA. ErrorState는 [다시 시도] 버튼 + 작은 오류 코드 캡션. 개발자용 에러 문자열은 절대 화면에 노출하지 않는다.
- `NbkBottomTabBar` — 홈 / 랭킹 / 내 계정 3탭. 활성은 honey 채움 아이콘 + text1 w700, 비활성은 외곽선 + text3. 라벨 11.
- `ThumbnailPlaceholder` — thumbPlaceholder 배경 + 이미지 아이콘, 모서리 12.

## 3단계 — 내비게이션 구조
- **스와이프 드로어를 제거**하고 하단 탭바(홈 / 랭킹 / 내 계정)로 바꾼다. 드로어에 있던 게시판 링크는 홈 상단 세그먼트 탭이 대신하므로 없앤다.
- 홈 상단바: 왼쪽 로고(육각 심볼 + '너반꿀✦' 워드마크), 오른쪽 이번 주 기간 캡션. 햄버거 없음.
- 홈 하단의 '내의견 등록하기' 가짜 입력 바를 제거하고, 탭바 위 오른쪽에 꿀색 확장 FAB **'손절 인증하기'**(연필 아이콘, 높이 48, 필)를 둔다. 비로그인이면 로그인 화면으로.
- Top3 섹션 헤더에 '전체보기 ›'(honeyDeep) → 랭킹 탭. 랭킹 화면 하단 '내 순위' 바 탭 → 내 계정.
- 용어 통일: 탭·게시판 선택·상세 상단 배지·마이페이지 배지 모두 **'주식' / '코인'**. '너반꿀'은 워드마크로만 쓴다. board=1 → 주식, board=2 → 코인.
- 글 작성 진입 시 현재 홈 탭(주식/코인)을 게시판 기본값으로 넘긴다.
- 로그인·내 정보·프로필 수정·글 작성이 끝나면 **직전 화면으로** 돌아간다(지금처럼 무조건 홈으로 가지 않는다).
